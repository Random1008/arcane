# Musiques d'ambiance (optionnelles)

Par défaut, une **boucle d'arpège synthétisée** joue selon le contexte. Pour remplacer une musique,
dépose un fichier **`<contexte>.mp3`** ici (servi à `/music/<contexte>.mp3`) — il sera joué **en
boucle** à la place de la synthèse, sans changer le code.

| Fichier | Contexte |
|---|---|
| `worldmap.mp3` | carte du monde |
| `biome.mp3` | exploration d'un biome / donjon |
| `boss.mp3` | combat de boss (biome-boss, donjon, Nexus) |
| `nexus.mp3` | Nexus Infini (hors boss) |

Référence : `src/game/audio/manifest.ts` · réglages volume/mute : panneau **F1**.
