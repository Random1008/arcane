Tu es un expert en UI/UX et en développement de jeux vidéo web (Phaser.js, JavaScript).

Je veux créer une INTERFACE GACHA ultra stylée pour un jeu 2D pixel art.

L’objectif est de créer une expérience immersive, addictive et visuellement impressionnante.

---

🎮 STRUCTURE DE L’UI GACHA :

Le système doit être divisé en 4 phases :

1. Écran d’invocation
2. Animation (suspense)
3. Reveal (révélation)
4. Résultat final

---

🎨 ÉCRAN D’INVOCATION :

Créer une interface avec :
- bouton "Invocation x1"
- bouton "Invocation x10"
- affichage des ressources (monnaie)
- bannière du gacha
- aperçu des récompenses possibles

Design :
- fond sombre (important)
- style pixel art
- couleurs néon
- petites animations (particules, glow)

---

🌌 ANIMATION GACHA :

Créer une animation immersive en plusieurs étapes :

1. Activation :
   - écran s’assombrit
   - effet sonore léger

2. Portail / cercle magique :
   - cercle qui tourne
   - effet de charge
   - lumière qui grandit

3. Couleur selon rareté :
   - vert = rare
   - bleu = épique
   - violet = légendaire
   - or = mythique
   - noir + glitch = secret

4. Ajouter du suspense :
   - animation lente
   - tension visuelle
   - montée sonore

---

💥 REVEAL (TRÈS IMPORTANT) :

Créer une révélation en plusieurs étapes :

- flash blanc
- apparition d’une silhouette
- zoom progressif
- apparition finale du compagnon

Ajouter animations :
- fade in
- zoom
- apparition stylée

---

🎇 EFFETS VISUELS SELON RARETÉ :

- Commun → simple
- Rare → léger glow
- Épique → particules
- Légendaire → aura lumineuse
- Mythique → halo + effets persistants
- Secret → glitch + tremblement + distorsion

Effets pour SECRET :
- écran qui tremble
- glitch visuel
- bruit spécial
- flash violent

---

🎁 ÉCRAN RÉSULTAT :

Afficher :
- sprite du compagnon
- nom
- rareté
- bonus/effets

Ajouter boutons :
- "Continuer"
- "Invocation suivante"

---

🎰 INVOCATION x10 :

Créer une animation spéciale :
- afficher 10 cartes
- retourner une par une
- suspense sur chaque tirage

Bonus :
- animation spéciale si légendaire ou plus

---

🎨 STYLE PIXEL ART :

- sprites pixel (16x16 ou 32x32)
- animations simples
- particules pixelisées
- effets lumineux stylisés

---

🔊 SOUND DESIGN :

Ajouter :
- clic bouton

---

🧠 UX AVANCÉE :

Créer du suspense artificiel :
- ralentir animation
- faire croire à une meilleure rareté
- surprise finale

---

💡 EFFETS AVANCÉS (OPTIONNEL) :

Ajouter :
- zoom caméra
- shake écran

- shader glitch
